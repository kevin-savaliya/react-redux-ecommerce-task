# React Redux E-Commerce Application

This project is a React-based e-commerce application developed as part of a practical task.  
It demonstrates clean frontend architecture, proper state management using Redux Toolkit, and integration with external APIs for authentication and product data.

---

## 🚀 Features

- User authentication using DummyJSON Auth API
- Secure JWT token handling using localStorage
- Protected routes after login
- Product listing fetched from DummyJSON Products API
- Add to Cart functionality using Redux
- Dynamic cart count displayed in the navigation bar
- Checkout page with selected products and total price calculation
- Clean and simple UI focused on usability

---

## 🧱 Tech Stack

- **React** (Functional components & Hooks)
- **Redux Toolkit** (State management)
- **React Router DOM** (Routing & protected routes)
- **Axios** (API calls)
- **CSS** (Custom styling)
